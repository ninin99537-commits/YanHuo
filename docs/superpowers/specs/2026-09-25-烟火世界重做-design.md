# 烟火 · 世界纯自转重做（Phase 1 核心）设计

日期: 2026-09-25
状态: 已批准。实施 Phase 1 = 数据模型 + 提示词 + 注入；Phase 2 = 「世界」页 UI。

## 背景与问题

当前提示词已含大量"禁止围着主角转"的否定指令，但实际输出仍围绕正文与主角，并常把事件故意引向主角、为难主角。根因不在禁止不够，而在结构反向拉扯：

1. 每条事件必填 `知晓`（主角专属台账）、`迫近`（只给波及主角所在区域的大事）；势力必填 `对主角态度`——三个字段每轮提醒模型"主角是中心"。
2. 任务消息中正文是最大输入，"世界自转"却没有独立素材源（势力也派生自正文/世界书），模型无米下锅，只能回头啃正文。
3. 大量否定指令稀释注意力，缺少"与主角无关的世界事件长什么样"的正面示范。

## 目标

- 事件生成完全不考虑主角：删除 `知晓`、`迫近`、`对主角态度`。
- 用五层常驻素材源让世界真正自转：地域、大势、伏笔、节令（开关）、指标（开关）。
- 提示词改为正面生成手册 + 一条硬规则（大多数事件的当事人与地点不在正文里）。
- 不预设世界观，一切产出贴合世界书设定的世界观（科幻卡不出现科举/王朝/仙门）。
- 适配"只读得到最近几层正文 +（可选）`<记忆回溯>`"的限制。

## 事件合格线

三问全过才算事件：

1. 集体/组织/制度/公共层面的动作或后果（政权、机构、势力、行业、阶层、市场、舆论、法律、军事、科技、宗教、文化）。
2. 会被跨地区的人当作议题/谈资/情报（报纸、网络、朝堂、商路、军报、行业圈）。
3. 对格局或某方处境有可累积的后果（推进/恶化/转折）。

一律不入账：天气与自然现象本身（下雨/降温/起雾）、基础设施日常故障与维护（停电/停水/修路/检修）、市井日常（店铺火爆/街头热闹）、任何人的个人起居。例外：升级为公共灾害（洪灾/断供/大规模伤亡）或成为势力博弈的直接对象。

各世界观正面锚点：

- 古代：边关战事、朝局变动、盐铁新政、灾荒流民、使团往来、科举舞弊案。
- 现代：政策转向与选举、企业并购与裁员潮、金融危机、重大诉讼、罢工、社会运动、外交摩擦、疫情、科技突破与监管、媒体风暴、体育文化盛事。
- 科幻：星际条约、殖民地独立、跃迁技术突破、舰队调动、AI 管制、资源垄断、外星接触、生态危机。
- 通用：势力更替、联盟破裂、市场崩盘、舆论转向、制度变革。

## 数据模型

删除：事件 `知晓`/`迫近`，势力 `对主角态度`，设置 `迫近闯入`。
保留：事件 `隐秘`（公开/隐秘）、`传播`、`渠道`、`规模`、`阶段`、`代表人物`。
`世界.大势`（一句话）更名 `世界.总览`，与结构化 `大势` 区分。

新增（常驻、增量维护、带滚动 `前情`）：

- 地域: `Record<名称, { 概况, 局势, 当权者, 对外关系, 最近变化, 前情 }>` ≤8
- 大势: `Record<名称, { 概况, 进展, 走向, 最近变化, 前情 }>` ≤5
- 伏笔: `{ 标题, 埋设, 指向, 成熟度: 酝酿|将熟|已爆发, 最近变化, 前情 }[]` ≤5
- 节令: `{ 名称, 周期, 时间, 概况 }[]` ≤6（开关）
- 指标: `Record<名称, { 值, 趋势: 上升|下降|平稳, 说明 }>` ≤6（开关）

五层内容按世界观填。节令：古代写庙会/汛期/科举，科幻写星港开市/舰队检阅/跃迁窗口。指标：古代写丰歉/物价/民怨，科幻写能源/民心/星际紧张度。

## 推进流程

- 每回合素材优先从五层产出：地域局势、大势进展、伏笔成熟/爆发、节令到来、指标涨落 → 事件。
- 正文降级为可选：只用于推时间、更新主角所在地域、以及可选的世界级涟漪；允许整轮不看正文。
- 硬规则：事件清单里大多数事件的当事人与地点都不在正文里。
- 世界书必读，世界观最高权威；`<记忆回溯>` 只作历史理解、不复述。
- 首次推进建档：从世界书+最近正文判断世界观，生成初始五层 + 势力 + 2~4 件进行中的事件。
- 增量维护（原样带回、只改变化、换血自检）保留，去掉全部主角条目。

## 注入

区块：世界总览 → 大势 → 地域 → 势力 → 公开事件（→ 隐秘事件，受开关控制）。
移除"主角已知/幕后动向"分区与迫近警告。给主 AI 的说明改为：这些是世界自己的动向，大多与主角无关；角色只能通过合理渠道得知，不许全知。

## 界面与设置

Phase 1：删除主角字段的 UI 引用、`世界.大势`→`总览`、设置加 `节令历法`/`世界指标` 开关、移除 `迫近闯入`，保证可编译。
Phase 2：「世界」页折叠展示 地域/大势/伏笔/节令/指标。

## 迁移

`DATA_VERSION` 升位；旧快照读入时丢弃 `知晓/迫近/对主角态度`，`世界.大势`→`世界.总览`，新五层缺省空，由下次推进积累。

## 历史限制

引擎只读得到最近几层正文；更早历史不在上下文里。世界连续性由引擎自己的快照承担，不因看不到旧正文就重复已发生的事。世界书中的 `<记忆回溯>`（记忆插件提供，可能不存在）可读来理解近况，不复述、不依赖。
