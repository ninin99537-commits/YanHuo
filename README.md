# 烟火 · 世界运转系统 (Yanhuo)

一个运行在**酒馆助手 (Tavern Helper)** 里的脚本: 主角看不见的地方, 时间照常流逝, 各方按自己的盘算行动。

它与《彼方》互补、分工明确: **彼方记"小事件"**——具体 NPC 的个人生活与行踪; **烟火只记"大事件"**——势力、群体、地区、天时与远方变化。主角只是世界里的普通一员, 世界不围着他转。

## 它做什么

每次 AI 完成一次正文回复后(频率可配, 防抖 800ms, 连发只推最后一条), 烟火用**你自己填的独立接口**(任何 OpenAI 兼容服务)推进世界, 结果整体写入本次分析的楼层(快照随楼层存亡):

- **世界纯自转**: 素材优先从五层常驻档案里长出来——地域 / 大势 / 伏笔 / 节令 / 指标——不依赖正文; 硬规则是事件清单里大多数事件的当事人和地点都不在正文里。
- **事件合格线**: 必须是集体 / 组织 / 制度 / 公共层面的动作或后果, 会被跨地区的人当作议题, 对格局或某方处境有可累积的后果; 天气、基础设施故障、市井日常、个人起居一律不入账。
- **隐秘事件**: 势力暗中行动默认只进面板、不注入主 AI, 事败或走漏后可翻转为公开。
- **注入主 AI**: 世界动向写入角色卡主世界书的常驻条目(蓝灯常开、禁递归), 主 AI 每回合都能读到。
- **读世界书与主 AI 完全一致**: 同样的激活逻辑(蓝灯常驻、绿灯按关键词扫最近正文), 条目里的模板与宏先求值再注入; 全局世界书默认不读、有开关, 支持按条目名与关键词排除。

## 面板

悬浮球(墨印, 可拖动、位置记忆)点开是面板(可拖动, 点外部不关闭, 再点悬浮球或关闭按钮收起):

- **此刻**: 世界时间 / 氛围 / 大势、迫近警告、进行中事态与势力速览, 以及推进 / 暂停自动 / 修笔 / 清空。
- **风闻**: 事件纪事流(最新在前), 按阶段与规模筛选, 每条带时间、地点、规模、传播、知晓、渠道与隐秘徽标, 可展开演变时间线。
- **势力**: 势力档案, 目标 / 动向 / 前情 / 势力范围 / 对外关系 / 头面人物。
- **世界**: 大势 / 地域 / 伏笔 / 节令 / 指标五类常驻档案, 可用「添一笔」手动建档。
- **日志**: 最近一次推进的完整请求与输出、注入给主 AI 的内容预览、控制台输出、一键「复制报错发给助手」。
- **设置**: 接口配置与命名预设、运转设置、楼层标签过滤、世界书读取范围与排除。

## 安装

1. 构建:

   ```bash
   pnpm install
   pnpm build
   ```

   产物是 `dist/烟火_世界运转/index.js`。

2. 在酒馆助手里新建一个脚本, 把该文件的内容粘进去并启用。

## 开发

```bash
pnpm install
pnpm build        # 生产构建
pnpm build:dev    # 开发构建
pnpm watch        # 边改边打包
pnpm test         # 跑全部测试
pnpm lint         # 代码检查
```

测试不需要酒馆环境: 平台能力通过一层接缝注入, 测试里塞一个假宿主就能把整条「世界推进」跑通。
